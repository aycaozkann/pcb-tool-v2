# Karar Günlüğü

Bu klasör, onaylanmış ve sonraki tasarım kararlarını etkileyen kısa kayıtlar içindir: seçilen fabrika, stackup, kritik komponent veya üretim hacmi gibi.

Yeni kayıt için [[../Templates/Karar_Kaydi|Karar Kaydı şablonunu]] çoğalt. Kesinleşmemiş konuları burada karar olarak kaydetme.
